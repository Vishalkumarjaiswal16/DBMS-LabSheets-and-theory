## 🧪 Lab Sheets Overview

### 🔹 Lab Sheet 1 — Foundation & Schema Design
- ER Diagram Design
- Table Creation with Primary Keys & Foreign Keys
- DDL Operations (`CREATE`, `ALTER`, `DROP`, `TRUNCATE`)
- DML Operations (`INSERT`, `UPDATE`, `DELETE`, `SELECT`)
- Views (`CREATE VIEW`, `DROP VIEW`)

### 🔹 Lab Sheet 2 — Transactions & Advanced Queries
- SQL Transactions (`BEGIN`, `COMMIT`, `ROLLBACK`)
- Savepoints (`SAVEPOINT`, `ROLLBACK TO SAVEPOINT`)
- Complex `SELECT` queries with conditions
- `INSERT` and `UPDATE` with constraints

### 🔹 Lab Sheet 3 — Advanced SQL & Control
- `GROUP BY` & `ORDER BY` clauses
- `JOIN` Operations (`INNER`, `LEFT`, `RIGHT`, `FULL`)
- Subqueries & Nested Queries
- TCL Commands (Transaction Control Language)
- DCL Commands (`GRANT`, `REVOKE`)
